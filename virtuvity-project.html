Peraturan

Baca dan pahami semua peraturan di bawah ini agar server tetap aman, nyaman, dan menyenangkan untuk semua member.

SERVER HANDBOOK / 01—21 21 peraturan
01⚔

Jangan membunuh sembarangan

Dilarang membunuh player tanpa alasan atau konteks yang masuk akal di dalam cerita.

02⊘

No cheat

Dilarang menggunakan cheat seperti X-ray, Kill Aura, dan sejenisnya. Main yang fair.

03ᴢᶻ

Hormati player AFK

Jangan membunuh atau mengganggu orang yang sedang AFK.

04♡

No baper

Masalah di game jangan dibawa ke grup. Pisahkan konflik karakter dari hubungan antar-player.

05⌂

Jangan rusuh base orang

Serangan base harus punya konteks konflik cerita. Jangan sampai bikin orang lain bosan main.

06▣

Usahakan bikin konten

Kalau bisa, rekam POV kalian dan upload ke TikTok, YouTube, atau platform lain yang sesuai.

07⚙

Jangan bikin server lag

Hindari mesin terlalu berat. Pikirkan dampaknya ke performa server dan player lain.

08♙

Usahakan aktif

Kalau sedang senggang, usahakan online. Yuk ramaikan server yang sudah dibangun bersama.

09♆

Jaga tempat AFK fishing

Dilarang menghancurkan atau merusak tempat AFK fishing milik bersama maupun player lain.

10▤

Bikin cerita yang masuk akal

Bebas bikin cerita, tapi jangan membuat karakter kebal atau tidak terkalahkan tanpa alasan jelas.

11♧

Jangan menekan player lain

Beri ruang buat semua orang mengembangkan cerita. Jangan mendominasi RP.

12♙♙

Maksimal 3 orang per tim

Jumlah member terbatas, jadi satu tim maksimal 3 orang agar kekuatan tetap seimbang.

13⬡

Trap hanya di base sendiri

Buat trap untuk pertahanan di base sendiri. Jangan memasang trap sembarangan di area umum.

14✹

Jangan hancurkan base tanpa sebab

Base orang bukan tempat latihan TNT. Harus ada alasan atau konteks cerita yang jelas.

15⚙

Admin wajib adil

Admin tidak boleh mengambil item GMC untuk Survival. Pisahkan akun Survival dan akun admin jika memungkinkan.

16▣

Bangun cerita yang menarik

Usahakan cerita punya perkembangan. Jangan sedikit-sedikit perang; variasikan alurnya.

17♧

Belajar mandiri

Coba cari solusi sendiri sebelum meminta bantuan admin untuk masalah yang bisa diatasi.

18▦

Jangan atur RP sebelumnya

Hindari mengatur kejadian RP di luar server. Biarkan pertemuan dan cerita berkembang alami.

19◉

Pisahkan info luar game

Jangan gunakan info dari POV musuh seperti koordinat base atau rencana mereka. Info luar server bukan pengetahuan karakter.

20☏

Jaga toxic saat RP

Karakter boleh marah dan toxic sewajarnya, tapi jangan menyerang player secara pribadi.

21⬡

Jangan serang player yang lag

Kalau player tiba-tiba lag saat perang, jangan manfaatkan situasi untuk membunuhnya. Tetap respek.

Peraturan tidak ditemukan. Coba kata kunci lain.
